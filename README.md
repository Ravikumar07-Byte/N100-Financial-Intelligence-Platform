\# N100 Financial Intelligence Platform



\## Project



Financial analytics platform for 92 companies from the Nifty 100 dataset.



\## Technology Stack



\- Python

\- Pandas

\- NumPy

\- OpenPyXL

\- SQLite

\- SciPy

\- Scikit-learn

\- Streamlit

\- FastAPI

\- ReportLab

\- Plotly

\- Pytest



\## Project Structure



\- data/raw/ — source Excel files

\- data/supporting/ — supplementary datasets

\- db/ — database schema

\- src/etl/ — data ingestion and validation

\- src/analytics/ — financial analytics

\- src/nlp/ — qualitative analysis

\- src/dashboard/ — Streamlit dashboard

\- src/api/ — FastAPI

\- src/reports/ — PDF reports

\- tests/ — automated tests

\- output/ — generated outputs

\- reports/ — generated reports



\## Important Data Note



Some supporting datasets, including stock price and market-cap data, are simulated as specified in the project execution plan. They must not be represented as live market data.
